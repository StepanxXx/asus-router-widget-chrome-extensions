# Smoke test розширення

## Підготовка

1. Виконати:

   ```bash
   npm install
   npm run check
   ```

2. Відкрити `chrome://extensions`.
3. Увімкнути **Developer mode**.
4. Натиснути **Load unpacked** і вибрати директорію `dist/`.
5. Відкрити сторінку ASUS-роутера та увійти в систему.

Після нової збірки на сторінці extensions потрібно натиснути **Reload** для розширення, а потім оновити вкладку роутера.

## Popup

- [ ] Popup відкривається без помилок.
- [ ] Відображаються кнопки `clients` і `networks`.
- [ ] Під час відкриття екрана кнопки тимчасово блокуються.
- [ ] На непідтримуваній сторінці popup показує контрольовану помилку.

## Networks

- [ ] Кнопка `networks` відкриває діалог.
- [ ] Після першого запиту зникає `Loading…`.
- [ ] Відображаються INTERNET, LAN та доступні Wi-Fi інтерфейси.
- [ ] Total і speed мають правильні напрямки RX/TX.
- [ ] Дані оновлюються приблизно раз на 2 секунди.
- [ ] Графіки з'являються після накопичення traffic samples.
- [ ] Повторне відкриття не створює другий діалог.
- [ ] Кнопка закриття видаляє діалог і зупиняє запити.

## Clients

- [ ] Кнопка `clients` відкриває діалог.
- [ ] Після першого запиту зникає `Loading clients…`.
- [ ] Online/login-клієнти розташовані першими.
- [ ] Відображаються connection type, RSSI, IP і MAC.
- [ ] Total, speed і напрямки трафіку коректні.
- [ ] Offline-клієнти не продовжують накопичувати history.
- [ ] Дані оновлюються приблизно раз на 2 секунди.
- [ ] Довгі або незвичні назви клієнтів не ламають таблицю.
- [ ] Кнопка закриття видаляє діалог і зупиняє запити.

## Перемикання та ізоляція

- [ ] Відкриття Clients закриває Networks.
- [ ] Відкриття Networks закриває Clients.
- [ ] Стилі діалогів не змінюють сторінку ASUS.
- [ ] Стилі сторінки ASUS не змінюють діалоги розширення.
- [ ] У консолі popup немає uncaught errors.
- [ ] У консолі сторінки немає uncaught errors від розширення.

## Перевірка cleanup polling

1. Відкрити Chrome DevTools → **Network**.
2. Відкрити Networks або Clients.
3. Переконатися, що відповідні запити повторюються раз на 2 секунди.
4. Закрити діалог.
5. Переконатися, що нові запити більше не з'являються.
